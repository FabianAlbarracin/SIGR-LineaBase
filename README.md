# Sistema Integral de Gestión de Restaurante (SIGR)

## Descripción

SIGR es una aplicación web orientada a la gestión operativa de restaurantes. El sistema está diseñado para administrar usuarios, pedidos, reservas, menús, facturación y reportes desde una única plataforma.

## Alcance de la línea base

La presente línea base corresponde a la versión inicial del proyecto y define los módulos, la organización técnica y la documentación base que servirán como referencia para futuras etapas del desarrollo.

## Módulos incluidos

- Autenticación y gestión de usuarios.
- Menú digital.
- Gestión de pedidos.
- Gestión de reservas.
- Facturación y cierre de caja.
- Reportes operativos.
